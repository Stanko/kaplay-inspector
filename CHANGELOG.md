# Changelog

## Version 0.4.3

### Added

- Inspect game objects directly in the game canvas, supports `area` component and render area.
- See GPU textures
- Inferred live-edit controls for boolean, number, text, vector, color and game object reference properties, including custom component properties
- Persist the inspector visibility, refresh interval, bounding-box setting and search term between browser refreshes
- Option to select a theme - light, dark or system

### Changed

- New toolbar with tooltips, sticky game object headers and polished UI
- Improved object-tree inspection with better component labels and support for manually detected local render areas
- Update the KAPLAY peer dependency to `^4000.0.0-alpha.27.1`.

### Fixed

- A bunch of small performance fixes
